# Princípio do Roadmap

Este roadmap não é uma promessa de que cada item será implementado exatamente da maneira inicialmente imaginada.

Ele registra nossa **direção técnica**.

Se durante o desenvolvimento descobrirmos que:

* uma abstração não é necessária;
* uma tecnologia não resolve nosso problema;
* determinado sistema precisa ser antecipado;
* uma arquitetura precisa ser refatorada;
* uma decisão anterior deixou de ser adequada;

o roadmap poderá evoluir.

Isso não representa falha de planejamento.

Representa **Engenharia de Software acontecendo em um projeto real**.
